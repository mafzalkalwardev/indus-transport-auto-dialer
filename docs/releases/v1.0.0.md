# v1.0.0 — Initial Stable Release

**Indus Transport Auto Dialer** — PyQt6 Windows auto dialer for permission-based dispatch calling with Google Voice integration.

## Highlights

- Multi-line Google Voice dialing with PyQt6 desktop UI
- Excel campaign import, CRM, call logs, live call monitoring
- Admin export packages for client/agent workstations
- Light and dark themes with documented screenshots
- Compliance and responsible-use guidance in README

## Install

```powershell
git clone https://github.com/mafzalkalwardev/indus-transport-auto-dialer.git
cd indus-transport-auto-dialer
pip install -r requirements.txt
python autodialer_gui.py
```

See `CLIENT.md` for agent deployment and `docs/RUNBOOK.md` for operators.

## Notes

- Do not commit `.env`, Chrome profiles, credentials, or real call logs.
- Use demo/sample contacts for testing and screenshots.
